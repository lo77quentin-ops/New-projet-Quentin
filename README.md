# 🧟 Zombie Survival

Voici un jeu de survie développer par moi en **JavaScript**, **HTML5 Canvas** et **Flask**.

## 🎮 Jouer au jeu

👉 https://new-projet-quentin.onrender.com

## Fonctionnalités

* Déplacement du joueur (ZQSD)
* Tir à la souris
* Zombies qui poursuivent le joueur
* Boss avec points de vie
* Collecte de pièces
* Système de score
* Gestion des munitions et rechargement automatique
* Pouvoir laser spécial
* Écran Game Over

## Contrôles

| Action        | Touche      |
| ------------- | ----------- |
| Avancer       | Z           |
| Reculer       | S           |
| Gauche        | Q           |
| Droite        | D           |
| Tir           | Clic gauche |
| Laser spécial | E           |

## Technologies utilisées

* Python
* Flask
* JavaScript
* HTML5 Canvas
